# Requirements

## Goal

A Zensical walkthrough that takes a reader from an unboxed Heltec WiFi LoRa 32 **V4** to a
working MeshCore **Companion (Bluetooth)** node paired with the MeshCore app.

## Functional

1. Document bootloader entry for Heltec V4 (USER/PRG + RST).
2. Document MeshCore web flasher steps for target **Heltec v4** and role **Companion · Bluetooth**.
3. Document local radio preset selection (NZ: **New Zealand (Narrow)**).
4. Document phone/web client pairing and a verify step (device visible / advert or chat).
5. Provide troubleshoot and reference pages.

## Non-functional

- Cite product behaviour; mark unverified steps until live evidence.
- Prefer screenshots and short steps.
- V4 only — no R8 comparison content in v1.
